<CaseSection title="Objective">
  A controller-to-node link whose key exchange is designed to stay secure against a future quantum
  adversary, by combining a post-quantum and a classical key exchange.
</CaseSection>

<CaseSection title="Architecture">
  <ArchDiagram
    label="VAJRA architecture"
    columns={[
      { title: 'Key exchange', nodes: ['Hybrid KEM: ML-KEM-768 + X25519'] },
      { title: 'Authentication', nodes: ['ML-DSA-65 signatures'] },
      { title: 'Transport', nodes: ['ChaCha20-Poly1305 over UDP'] },
    ]}
  />
  <p>One controller, one node, one link: point-to-point. There is no multi-hop routing.</p>
</CaseSection>

<CaseSection title="Constraints">
  The parameter sets are NIST Category 3, not CNSA 2.0. Peer identities are pinned in configuration;
  there is no certificate authority or revocation.
</CaseSection>

<CaseSection title="Hardware and firmware">
  The frozen core is written in Rust, with a Python reference implementation. The handshake and
  record layer are also modelled in ProVerif; those models are not yet machine-checked. This project
  is restricted: this page covers architecture and results only.
</CaseSection>

<CaseSection title="Measurements">
  <ul>
    <li>Rust test suite: 16 tests pass at v1.0.</li>
    <li>Python reference: 53 of 53 tests pass.</li>
  </ul>
</CaseSection>
