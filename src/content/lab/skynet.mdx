<CaseSection title="What it is">
  A dual-brain aircraft stack: a Pixhawk flight controller handles real-time control, and a
  Raspberry Pi companion runs the mission, the safety gates, and a live telemetry dashboard. The
  aircraft carries GPS, optical flow, and a barometer. This project is restricted: this page covers
  architecture and results only.
</CaseSection>

<CaseSection title="Result">
  <ul>
    <li>
      Nominal 2 m mission in ArduPilot SITL: climbed to 2.07 m, held about 1.96–2.00 m, landed and
      disarmed.
    </li>
    <li>
      Companion killed mid-hover: the autopilot switched to LAND after 4.2 s and disarmed on the
      ground at 15.6 s.
    </li>
  </ul>
  <p>
    Both are simulation results. The code is deployed to the Raspberry Pi but has not yet been run
    against the real Pixhawk or airframe.
  </p>
</CaseSection>
