# How to use these prompts

1. Create an empty repo. Copy `AGENTS.md` and `SITE_SPEC.md` into its root.
2. Open Claude Code in the repo. Paste the phase prompts one at a time, in order:
   - `01_PHASE0_PHASE1.md` — design plan (reply "approved" when happy), then the foundation build
   - `02_PHASE2_CONTENT.md` — content system, case studies, Lab, About
   - `03_PHASE3_MOTION.md` — X-ray lens hero, type reveal, hardware hall, transitions
   - `04_PHASE4_LAUNCH.md` — SEO, analytics, QA, launch
3. Start each phase in a fresh session. Review the report and preview deploy before moving on.
4. Before Phase 3 you need: a top-down Saarthi photo, KiCad SVG plots (F.Cu, B.Cu, F.Silkscreen) aligned to it, and GLB models. Phase 2 generates the full `ASSETS.md` list.
5. Before Phase 4 you need: the domain, contact email, résumé PDF, and at least one real client case.
